# 一箭又一箭 (One Arrow After Another)

## 游戏简介

点击箭头，让它飞出去。如果前方有阻挡，箭头会晃动并消耗失误次数。清空所有箭头即可过关。

## 开发环境

- Python 3.11
- Pygame 2.6.1

## 安装和运行方法

1. 安装 Python 和 Pygame: `pip install pygame`
2. 运行游戏: `python main.py`

## 游戏操作说明

- 鼠标左键点击箭头
- 按 F1 键重新开始当前关卡
- 游戏结束/通关后，按任意键重新开始
